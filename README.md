# Veyu Marketplace


Veyu is an all-in-one digital platform where you can buy, sell, rent, or list any type of vehicle — including cars, bikes, boats, aircraft, and more. Whether you're a private owner or a dealership, Veyu connects you with a global audience.

## Features

### Buy and sell vehicles

- Browse listings, filter by category, location, or price
- Contact the seller directly or through our secure in-app messaging or checkout system
- Use our financing options if available

### Rent vehicles

- Book, pay, and manage rentals directly from the app
- Choose from short-term and long-term rentals for various vehicle types

### Dealer dashboard

- Upload bulk inventory
- Sync listings with your dealership software
- Manage leads and automate updates

### User experience

- View vehicle details, features, and photos
- Leave reviews and ratings for other users
- Save favorite listings and search history

## Getting started

1. Clone the repository
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`

Note: You'll need to sign up for Google Maps API and replace the API key in `public/index.html` with your own.
